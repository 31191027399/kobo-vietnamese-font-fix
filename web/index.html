Vietnamese add-on

Kobo Vietnamese Installer

Add Vietnamese fonts, the optional Kobo Vietnamese language, and English–Vietnamese dictionaries without replacing your Kobo tools or personal data.

Checking for Kobo…

Connect the device by USB and tap Connect.

1

Optional prerequisite

Install tools first

If you want NickelMenu or KOReader, install them with KoboPatch Web UI, safely eject, and let the Kobo restart. Then reconnect it and return here. Already installed? Continue below.

2

Connect

Connect your Kobo by USB

On the Kobo screen, tap Connect. Your books, reading progress, settings, and plugins stay on the device.

3

Install

Install Vietnamese support

This installs the font fix, adds Extra: vi to Kobo’s language list, and installs the Kobo dictionary. If KOReader is already present, it also installs the KOReader dictionary. Existing target files are backed up first.

Checking the installation package…

Dictionary files are downloaded directly from redphx’s official release and verified before installation.

4

Eject

Safely eject and restart

After installation completes, eject the Kobo. Unplug the cable and let the Kobo restart. The font and language pack activate during that restart.

Advanced options

Install only one item

Use this only when repairing or updating part of the setup.

Sources: Kobo Tiếng Việt · redphx/tudien dictionaries · KoboPatch Web UI

Rebuild the font package

Creates a font-only KoboRoot.tgz from the 20 fonts sourced from Kobo Tiếng Việt by redphx. No compiler, Docker, NickelMenu, or KOReader is added.

Repair a KoboRoot.tgz only

Use this for a custom KoboRoot.tgz that is not NickelMenu. It keeps every non-font file unchanged and adds the Vietnamese fonts. It does not install or update NickelMenu.
