Local Kobo setup

Kobo Vietnamese Installer

Install the Vietnamese font fix, KOReader, and SimpleUI on your Kobo in three simple steps.

Checking for Kobo…

Connect the device by USB and tap Connect.

1

Connect

Connect your Kobo by USB

On the Kobo screen, tap Connect. Then choose Check Kobo above. Your books and reading progress stay on the device.

2

Install

Install everything

This installs the Vietnamese font fix, updates KOReader, and installs SimpleUI. A recovery backup is created automatically before any changes.

Checking the installation package…

For most Kobo H2O devices, this is the only button you need.

3

Eject

Safely eject and restart

After installation completes, eject the Kobo. Unplug the cable and let the Kobo restart. The Vietnamese fonts activate during that restart.

Advanced options

Install only one item

Use this only when repairing or updating part of the setup.

Rebuild the font package

Only use this after changing the bundled source or fonts. Docker Desktop is required.

Repair another NickelMenu version

Choose that version’s KoboRoot.tgz. The installer keeps its NickelMenu files and adds the 16 Vietnamese fonts.

Repair a KoboRoot.tgz only

Use this for a custom KoboRoot.tgz that is not NickelMenu. It keeps every non-font file unchanged and adds the Vietnamese fonts. It does not install or update NickelMenu.
