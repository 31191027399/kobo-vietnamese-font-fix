A simple path

Install in four steps

01

Open in Chrome or Edge

Use the deployed HTTPS page. Direct folder access is currently supported by Chromium-based browsers.

02

Connect your Kobo

Connect it with a USB cable, then tap Connect on the Kobo screen. Check that the installer shows the correct device.

03

Choose and patch

Select any independent components and press Patch selected items. Keep the cable connected until the page says Staged.

04

Eject and restart

Eject the Kobo in Finder or your file manager. Wait for it to disappear, unplug the cable, and let the Kobo finish restarting.

Fonts and interface language require Kobo firmware 4.x. The KOReader dictionary requires KOReader to be installed first. Keep a backup before modifying any device.
